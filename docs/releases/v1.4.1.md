# v1.4.1 - Runtime Security Updates

**Release status:** tag `v1.4.1` is on commit `0f9efa9`; both images were
promoted successfully. The GitHub Release has not yet been created. Repository
visibility is a separate decision.

## Changes

- Override the Core's transitive Guava and snappy-java dependencies and update
  the affected operating-system packages when building its runtime image.
- Update the Gateway's distroless base and temporarily copy the fixed Debian 13
  zlib library and its package metadata into the non-root runtime. The pinned
  package must remain available in Debian's configured repositories. Remove
  the temporary stage when the distroless base includes the fix.
- Update the console's Storybook and zod, and update vulnerable transitive
  dependencies and test tooling in the JavaScript modules. Targeted pnpm
  overrides keep compatible patched versions until upstream constraints and
  lockfiles can be updated without them.

On 8 November, `pnpm audit` reported no HIGH or CRITICAL findings in the three
JavaScript modules after the dependency updates. It still reported MODERATE
findings in `glob` and `minimatch`. Production-only audits returned no findings
for the console or simulator, and one MODERATE `minimatch` finding through
`@fastify/otel` for the Gateway. In the current integration, tracing is disabled
by default; when enabled, this dependency matches application route definitions
against an optional operator-controlled `OTEL_FASTIFY_IGNORE_PATHS` pattern.
This limits the observed input path but does not prove the vulnerability is
unexploitable. The patched `minimatch` version is a new major; replacing it
outside the upstream dependency range or migrating OpenTelemetry requires a
separate compatibility review. Development-only `glob` and `minimatch`
findings also remain; audit results can change as advisories are updated.
