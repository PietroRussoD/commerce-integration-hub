# v1.0.0 - Governed Operator Workflows and Versioned Contracts

`v1.0.0` consolidates the portfolio project into a versioned integration
baseline with inspectable architecture, explicit contracts, and controlled
operator recovery boundaries.

## Highlights

- The Connector Gateway publishes a generated OpenAPI contract with a drift
  check; the canonical Kafka event boundary is documented in a versioned
  AsyncAPI contract.
- The Operator Console includes an interactive System Map with links to the
  relevant implementation and documentation, alongside the recorded Flow
  Explorer scenarios.
- Core and Gateway operator APIs support opt-in external OIDC JWT validation.
  Read access requires `operator` or `platform-admin`; controlled Gateway
  delivery replay requires `platform-admin`.
- Gateway delivery inspection exposes payload-free summaries, detail, attempt
  history, and stable cursor pagination. An eligible exhausted delivery can be
  replayed only with a rationale and UUID idempotency key.
- The Gateway writes an immutable PostgreSQL command-audit journal covering
  reservation, state transition, and terminal command result in the same
  transaction as the durable replay decision.
- The Operator Console keeps a manually supplied non-expired token in page
  memory only. The Gateway, not the browser, verifies token signatures and
  enforces authorization.

## Security And Operational Boundary

The default local Compose demo does not include an identity provider, so OIDC
authorization remains disabled unless explicitly configured. The Console does
not implement login, token issuance, refresh, user storage, or role management.

Gateway replay is intentionally narrower than general failure recovery. Outbox
and Kafka dead-letter replay tooling, authenticated reindex initiation,
distributed tracing export, alert rules, and payload cleanup after its
retention period remain outside this release.

## Upgrade Notes

All repository modules advance together from `1.0.0-SNAPSHOT` to `1.0.0` under
the single-version policy. The release introduces no new database migration.
Existing PostgreSQL data and OpenSearch indexes remain compatible.
