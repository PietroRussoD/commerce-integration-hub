# v0.7.0 - Integration Flow Explorer

`v0.7.0` adds an accessible Integration Flow Explorer to the Operator Console.
It replays sanitized evidence from deterministic local `ERP_B` Compose
scenarios so that a reviewer can inspect successful processing, permanent
mapping rejection, and provider authentication failure without a running
environment or fabricated client-side service activity.

## Highlights

- A versioned, runtime-validated `FlowTrace` contract accepts only bounded,
  ordered, causally consistent scenario data.
- Three self-cleaning capture runners derive success, poison-item, and
  authentication-rejection artifacts from disposable local Compose stacks.
- Captured artifacts retain diagnostic correlation identity and durable state
  evidence while excluding credentials, request and response bodies, free-form
  errors, connection values, and internal row identifiers.
- The lazy-loaded console route provides scenario selection, a participant
  stage, an operable timeline, step evidence, and play, pause, restart, and
  direct-selection controls.
- Presentation timing is deliberately separate from captured timing: short
  transitions remain inspectable and long operational waits do not stall the
  demonstration.
- The console supports English and Italian and respects reduced-motion
  preferences by disabling autoplay while retaining manual controls.

## Reliability And Security Boundary

The Explorer is a read-only presentation of committed capture artifacts. It
does not call live integration services, mutate business state, expose demo
control endpoints, or claim production latency. React validates the artifact at
load time and renders only the closed contract.

The three artifacts are reproducible local evidence, not an audit log,
distributed trace, monitoring backend, or substitute for production incident
investigation. New scenarios require a capture runner, an artifact that passes
the runtime contract, and matching browser coverage before they are exposed.

## Upgrade Notes

This release changes only the Operator Console package, from
`0.7.0-SNAPSHOT` to `0.7.0`. It adds committed static trace artifacts and no
database migration, Integration Core API change, Connector Gateway migration,
or container-image release.
